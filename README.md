# PPT Color

PPT·디자인 작업 시 어울리는 색상 팔레트를 추천해주는 웹앱입니다.

## 기능

- **태그 선택** — Pastel, Dark, Warm 등 12가지 태그로 팔레트 탐색
- **팔레트 순환** — 같은 태그를 다시 누르면 다음 팔레트로 전환 (태그당 3가지)
- **Random** — 색채이론 기반 무작위 팔레트 생성
- **PPT 미리보기** — 선택한 팔레트가 실제 슬라이드에서 어떻게 보이는지 즉시 확인
- **HEX 복사** — 색상 클릭 시 HEX 코드 클립보드 복사

## 기술 스택

- Vanilla HTML / CSS / JavaScript
- 외부 라이브러리 없음 (완전 무료)
- Cloudflare Pages 배포
